As normas QP não estabelecem automaticamente as paletas, fontes e voz das outras marcas. Para Viajo Mucho e Rodon, o template escolhido é evidência de aplicação daquela peça, não um manual universal. As demais marcas têm logos catalogados; diretrizes específicas ausentes devem permanecer como lacuna.

Para co-branding, use os arquivos corretos de cada marca e a composição documentada no original escolhido. Não inventar uma margem mínima numérica: o conteúdo mockado do código trazia exemplos que não foram promovidos a regra.
